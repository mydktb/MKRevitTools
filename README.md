# MKRevitTools

A Revit add-in built with C# and the Revit API, providing tools for
view template filter management and automated sheet creation.

## Commands

- **Add Filters to View Template** — add filters to view templates via a
  WinForms UI
- **Create Sheets** — create sheets from within Revit
- **Create Sheets from Excel** — generate sheets from Excel data using EPPlus
- **Delete Filters** — batch delete filters

## Features

- WinForms UI for each command
- Custom UI theming (AppTheme)
- Excel integration via EPPlus
- Packaged .addin manifest
- Post-build deployment to Revit add-ins folder

## Built with

- C#
- Revit API (2025)
- .NET Framework 4.8.1
- EPPlus (Excel)
- WinForms

## Status

Working add-in. Source available in this repository.
